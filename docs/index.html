moneyspeak

Turn a currency amount into a string a speech synthesizer reads correctly.

GitHub npm

Install

pnpm add moneyspeak

Call it with an amount, a currency and a locale. It returns the string to speak and the conventional form to show.

import { verbalizeMoney } from "moneyspeak";

const result = verbalizeMoney({ amount: 123.45, currency: "SGD", locale: "en-US" });

result.spoken;   // "123 Singapore dollars and 45 cents"
result.display;  // "SGD 123.45"
result.strategy; // "major-minor"

On a page, give assistive technology the spoken form and keep the conventional form for sighted users.

import { setAccessibleMoney } from "moneyspeak/dom";

setAccessibleMoney(el, { amount: 123.45, currency: "SGD", locale: "en-SG" });
